## Scopo

Il campo Elenco immagini fornisce un elenco a discesa di file immagine da selezionare
per la visualizzazione nell'output dell'articolo in un elenco separato da spazi.

## Creazione del campo

Le opzioni speciali all'interno di questo campo sono:

- **Directory** Il percorso del file system alla directory contenente i file immagine
da elencare. È possibile selezionare immagini da una sola directory.
- **Multiplo** Consente di selezionare più valori.
- **Classe immagine** La classe da aggiungere all'immagine. Ad esempio *w-25 p-1*
limita la larghezza di ogni immagine al 25% del contenitore e aggiunge 1 unità
di spaziatura interna.

![creazione del campo elenco immagini](../../../en/images/fields/adding-custom-fields-images-list-field/01-fields-images-list-edit.png)

**Nota:** In questo esempio, l'inclusione del tipo di campo nel Titolo serve solo a
scopo dimostrativo. Nei titoli dei propri campi, ometterla.
