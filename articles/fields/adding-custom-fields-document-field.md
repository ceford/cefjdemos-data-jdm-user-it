## Scopo

Il campo Documento consente di selezionare un file di documento da una cartella di file.

## Creazione del campo

I parametri comuni dei campi sono descritti in un articolo separato.

* **Titolo** Il titolo viene visualizzato e utilizzato nell'elenco dei campi.
* **Etichetta** Questo è ciò che viene visualizzato nell'output. Se lasciato vuoto, viene impostato
dal contenuto del campo Titolo, ma può essere modificato.

![creazione del campo documento](../../../en/images/fields/adding-custom-fields-document-field/01-fields-document-edit.png)

**Nota:** In questo esempio, l'inclusione del tipo di campo nel Titolo è esclusivamente a
scopo dimostrativo. Nei titoli dei propri campi, ometterla.

## Immissione dei dati

Il campo Documento è semplice da utilizzare. Si seleziona il file di documento richiesto utilizzando un
selettore multimediale. 

Lo screenshot seguente mostra un file audio selezionato:

![immissione dei dati del campo documento](../../../en/images/fields/adding-custom-fields-document-field/02-fields-document-data-entry.png)

I campi vengono visualizzati in un articolo solo se compilati nel modulo di immissione dei dati dell'articolo.
